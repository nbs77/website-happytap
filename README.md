# HappyTab Website

This repository contains the public landing page for HappyTab, a Shopify-friendly customer satisfaction tool for WhatsApp review automation.

## What is included
- Responsive landing page
- Features, pricing, and testimonials sections
- Privacy Policy and Terms of Service pages
- LTR English layout for a modern SaaS-style presentation

## Files
- [website/index.html](website/index.html)
- [website/privacy.html](website/privacy.html)
- [website/terms.html](website/terms.html)

## Deployment
The site is designed to be published as a static website on Vercel, GitHub Pages, or any similar platform.
